==================================================

1. هدف

==================================================

این سند واژه‌نامه رسمی پروژه ERP SaaS است.

تمامی طراحی‌های معماری، پایگاه داده، Backend، Frontend، API، مستندات و توسعه نرم‌افزار باید از اصطلاحات این سند استفاده کنند.

هر اصطلاح در کل پروژه فقط یک معنی دارد.

==================================================

2. قوانین کلی

==================================================

 -01هر مفهوم فقط یک نام رسمی دارد.

 -02استفاده از مترادف برای یک مفهوم ممنوع است.

 -03تمام نام‌گذاری‌ها باید مطابق این سند باشد.

 -04هر اصطلاح جدید قبل از استفاده باید به این سند اضافه شود.

 -05این سند مرجع نهایی تفسیر مفاهیم پروژه است.

==================================================

==================================================

--------------------------------------------------

Service

لایه منطق کسب‌وکار.

--------------------------------------------------

DTO

Entity

--------------------------------------------------

11. قوانین استفاده

==================================================

1. تمامی جداول، کلاس‌ها، APIها، Eventها و مستندات باید از اصطلاحات این سند استفاده کنند.

2. استفاده از نام‌های جدید بدون ثبت در این سند مجاز نیست.

3. هر اصطلاح فقط یک مفهوم دارد و در کل پروژه با همان مفهوم استفاده می‌شود.

4. تغییر در مفاهیم این سند فقط با تصویب معماری پروژه مجاز است.
